# adapters/ — 可选参考，默认不用

**InkQueue 主路径不依赖任何 skill / adapter。**

日常请直接：

```bash
node agent/inkq.js …
```

并遵守 `../interface.md`。

本目录仅在「某家 Agent 产品强制要求 skill/规则文件形态」时当抄写参考。  
**不要安装、不要当依赖、不要在文档里当主流程宣传。**

| 路径 | 说明 |
|------|------|
| `hermes/SKILL.md` | 若你坚持用 Hermes skill 形态，可自行复制；非必需 |
| `codex/AGENTS.snippet.md` | 可粘贴片段；非必需 |

新增 Agent ≠ 新增协议：只可能多一份可选说明书，**禁止** fork `inkq.js`。
